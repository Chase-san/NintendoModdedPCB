# DMG-A02-MOD

This is an F-RAM and battery holder upgrade to the DMG-A02-10. This board is good for Pokemon Red, Blue, and Yellow as well many other games.

## Components

This board features a 32-pin ROM and a 28-pin RAM module.

| Ref   | Package     | Description  | Notes | Part |
| :---: | :---------: | :----------- | :---- | :--- |
| U1    | SSOP-32W    | Program ROM  | | |
| U2    | LQFP-32     | MBC-5        | | |
| U3    | SOIC-28W    | F-RAM        | | |
| U4    | TSOP-6      | Clock Sync   | OR Gate | 74LVC1G332GV,125 |
| C1, C2, C3, C4, C5 | 0603 (in)   |  0.015uF - 0.1uF Capacitor | |
| C6    | 0603 (in)   | 33pF Capacitor | May be left empty | |
| R1    | 0603 (in)   | 10k Ohm Resistor | | |
